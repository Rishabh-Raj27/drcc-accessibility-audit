# Accessibility Audit Report

## 1. Website Audited

Website: 7 Nischay Yuva Upmission, Bihar

URL: https://www.7nishchay-yuvaupmission.bihar.gov.in/

## 2. Audit Method

The website was evaluated using Google Chrome Lighthouse Accessibility
audit and manual keyboard navigation testing.

The Lighthouse accessibility score was 73.

## 3. Accessibility Issues Found

### Issue 1: Missing Alt Attributes

Lighthouse reported that image elements do not have alt attributes.

### Issue 2: Links Without Discernible Names

Lighthouse reported links without discernible names.

### Issue 3: Insufficient Color Contrast

Lighthouse detected insufficient foreground and background contrast.

### Issue 4: Missing Language Attribute

The HTML element does not contain a lang attribute.

### Issue 5: Insufficient Touch Target Size

Lighthouse reported that touch targets do not have sufficient size or spacing.

## 4. Conclusion

The audit identified several accessibility improvements related to
alternative text, link naming, color contrast, document language and
touch target sizing.
