# Project Architecture

## Project Overview

This project is an accessibility audit and full-stack project foundation
for a public-facing service website.

## Client

The client directory is reserved for the frontend application.
It will contain accessible UI components, semantic HTML,
responsive layouts and keyboard-friendly interactions.

## Server

The server directory is reserved for backend APIs and
server-side application logic.

## Documentation

The docs directory contains the accessibility audit report
and project architecture documentation.

## Audit

The audit directory contains the completed accessibility
audit worksheet.

## Screenshots

The screenshots directory contains evidence collected
during the Lighthouse accessibility audit.

## Tests

The tests directory is reserved for accessibility,
functional and responsive testing documentation.

## Future Development

The project can be extended with a frontend application,
backend APIs, automated accessibility testing and
accessibility improvements based on the audit findings.
